# 仕組み：進行フラグ


クリアに必要な条件（フラグ）と、その順番。出典は Web の攻略情報と2人の解説動画。実機の走りでも、下の表の順番でクリアまで通った。

## 1. ゴールの日付は決まっている

- 1年 ＝ 6か月 ＝ 168日。1か月 ＝ 4週 ＝ 28日。
- 季節：1月 春 ／ 2・3月 夏 ／ 4月 秋 ／ 5・6月 冬。
- 全宇宙野菜コンクールは毎年 1/1 だけ。最初に出られるのは 3年目 1/1（アストロドーム）。3年目 1/1 に勝つと称号「スピードキング」。これより早くは勝てない。
- つまり、ゲームの中で過ぎる日数（1年目 1/1 → 3年目 1/1 の 336日）は変えられない。RTA で縮められるのは、1日を進める速さと、メニュー操作の手数だけ。

## 3. 改造（進行に要る範囲）

段階ごとの値段・買う所・性能は [交配と強化種](11_仕組み_交配と強化種.md) にまとめてある。進行に関わるのは次の点。

- 交配マシンは2号から、交配で必ず属性値が変わる（初号機は 50%）。強化種も2号から作れる。
- 交配マシンの3号・4号・ファイナルはパンタロン町、ピートのスーパーとファイナルはソンブレロ市で改造する。
- 改造は1日に1段までで、改造した日は交配できない。

## 4. アストロキングまでの交配の系統

下の行ほど上位の野菜。季節の決まった野菜は、その季節にしか植えられない。

| できる野菜 | 親の組み合わせ | 季節 |
| --- | --- | --- |
| スイカタワー | ホタル唐辛子 ＋ トゲガーリック | 夏 |
| 月面コンブ | ホタル唐辛子 ＋ 真空ワカメ、または トゲガーリック ＋ イチゴブドウ | 冬 |
| 冥王マツタケ | 月面コンブ ＋ スイカタワー | 秋 |
| チンゲンツリー | 冥王マツタケ ＋ スイカタワー | 通年 |
| 銀河ドリアン | 月面コンブ ＋ 冥王マツタケ | 通年 |
| 妖精ピーマン | 月面コンブ ＋ チンゲンツリー | 通年 |
| 貴婦人 | 月面コンブ ＋ 銀河ドリアン | 通年 |
| 水晶ハーブ | 妖精ピーマン ＋ チンゲンツリー、または 貴婦人 ＋ 銀河ドリアン | 春 |
| アストロキング | 水晶ハーブ ＋ 貴婦人 | 通年 |

- ホタル唐辛子とスイカタワーの種は、ソンブレロ市の種屋で 20000z ずつ買える。
- 超遅成（13〜14日）は貴婦人とアストロキング。
- 交配は種どうしでできる。季節が効くのは「育てて種を増やすとき」と「コンクールに出す野菜を収穫するとき」。交配で種を使うので、種を増やすために育てる必要がある。
- 季節外れの野菜は畑に植えられない。
- アストロキングは超遅成（13〜14日）。大きさがレベル5以上だと +1日。3年目 1/1 に出すには、遅くとも 2年目 6月の中ごろに植える。
- すべての組み合わせは [交配の全組み合わせ](14_交配の全組み合わせ.md)。

## 5. 1日にかかる時間

実機で測った目安。トラップ戦は SELECT で飛ばした場合。

| 場面 | 時間 |
| --- | --- |
| バブーが来ない日の日送り | 約3秒（うち暗転は約1秒） |
| バブーが1匹来て、罠で守れた夜 | 13〜15秒 |
| バブーが1匹増えるごと | 約8.5秒増える |
| 罠を抜かれて畑まで入られた場合 | 守れた夜より約2秒増える |
| 畑を開く日 | 畑の作業で約20秒増える |

トラップ戦の視点を真上からにすると、1匹あたり約0.5〜0.8秒縮む。
