# 検証の結果

実機（PS3、ゲームアーカイブス版）の録画から測った結果のうち、走りの判断に役立つものをまとめました。測ったのは 2026年10月です。

## 1. 夜の長さ

14本の録画の約440晩を測りました。

| 場面 | 長さ |
| --- | --- |
| バブーが来ない夜の暗転 | 約1秒 |
| YES からトラップ戦まで | 約6.5秒 |
| トラップ戦（SELECT で飛ばした残り） | 約2.4〜2.7秒 |
| トラップ戦から朝まで | 約4.7〜5.2秒（1月より5月が約0.3秒長い） |
| 1匹来て守れた夜の合計 | 13.2〜14.5秒 |
| 2匹来た夜 | 約8.5秒長い |
| 食べられた夜 | 守れた夜より約2秒長い |

- 罠の数と種類では、読み込みは変わりません。罠は守れるかどうかだけで選べます。
- 2月の中で罠を3個、11個、6個と変えても、朝までの暗転は 4.77〜4.87秒でした。

## 2. トラップ戦の視点

| 視点 | トラップ戦の場面 |
| --- | --- |
| 初め | 約2.5秒 |
| 真上から | 約1.7秒 |
| バブーの後ろから | 約2.4秒 |

- 真上からにすると1匹あたり約0.8秒縮み、通しで約4分の見込みです。
- 畑の視点では時間は変わりません。畑に入るのは 0.8秒、出るのは 0.4秒でした。

## 3. ゴールデン強化種の率

バブーに野菜を食べられたあと、低い確率で落ちます。

| 測り方 | 食べた数 | 落ちた回数 | 率 |
| --- | --- | --- | --- |
| 2年 3/25 のセーブからくり返し | 184匹 | 7回 | 3.8%（95% の幅 1.5〜7.7%） |
| 2年 4/11 のセーブからくり返し | 310匹 | 4回 | 1.3%（同 0.4〜3.3%） |
| 罠なしで 3/25 から 6/1 ごろまで通し（10本）、4/10 まで | 135匹 | 3回 | 2.2% |
| 同じ10本、4/11 以降 | 441匹 | 9回 | 2.0% |

- 食べさせ続けると落ちにくくなる、という見立ては否定しました。4/11 以降に10本で9回以上なら否定すると、先に決めて測った結果です。
- ロードし直すと、来る数、食べる株、ゴールデンの有無は毎回変わります。
- 特定のバブーに偏るかは確かめられていません。3/25 のセーブでは、落ちた夜のバブーは6種類以上にばらけていました。
- 率 2.0%、1日 0.94匹で計算すると、2年 3/7 から 5/22 までに出る見込みは約75%、6/13 までで約83%です。
- 1年目 1/9 の夜に落ちた例もあります。

## 4. 罠が突破される率

いまのルートに近い形で走った録画から数えました（2026-10-27 時点）。

| 罠 | 期間 | 来た夜 | 突破 | 1晩の率 |
| --- | --- | --- | --- | --- |
| ピートの初期配置 | 1/1〜1/9 | 22 | 0 | — |
| カカシ3体 | 1/10〜1/31 | 117 | 1 | 約0.9% |
| カカシ3体 | 2/1〜2/14 | 61 | 3 | 約4.9% |
| 川流し | 2/15〜2/20 | 33 | 0 | — |
| 風船 | 2/21〜3/31 | 85 | 1 | 約1.2% |

- 突破の数が少ないので、率の幅は大きいです。カカシの2月は、ありそうな幅で約1〜14%です。
- この表のあと、序盤の交配をやめた形で走ると、1月の突破が12本中6本ありました。率は走りの内容で変わる可能性があります。

## 5. バブーの進化

1〜3は走者の実験の見立てで、回数は記録していません。4は録画で確かめました。

1. 迂回型に進化したバブーは、二度と退化しない可能性が高い。一度迂回されたら、同じ罠に戻さず次の形へ進む。
2. 扇風機には、すぐ風の耐性がつく。
3. 川流しは、ジャンプ台を強力ジャンプ台にして風船を使うと、かなり長持ちする。
4. パンチングマシンも迂回される。安定した走りもあったが、3/28 に替えて 4/1 と 4/5 の夜に突破された走りもある。

1 は、Web の資料にある「罠なしを1回経験させると能力が一気に下がる」という説明と食い違います。理由は分かっていません。

## 6. 畑の収穫と植え付けの順番

畑1の6株を収穫して次の6個を植えるまでを、3回ずつ比べました。

| やり方 | 平均 |
| --- | --- |
| 全部収穫してからまとめて植える | 14.10秒 |
| 1つ収穫して植えるをくり返す | 13.84秒 |

差は約0.3秒で、回ごとのばらつき（約1秒）より小さいです。押し間違えにくいほうを選んでかまいません。
