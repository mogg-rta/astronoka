# 交配の全組み合わせ



## 規則

- 子のメンデル数は、両親のメンデル数の足し算。
- 子の科は、両親が同じ科ならその科、違う科なら残りの科（A ＋ B → C など）。
- その科・メンデル数の野菜が無ければ、新しい野菜はできない（親のどちらかか、くず野菜）。
- 同じ野菜どうしの交配は、強化種ができる条件（Wiki）。必ず強化種になるのではなく、できるかどうかは交配マシンの性能で決まる率による（ならなければ普通の種）。新しい野菜はできないので、この一覧には入れていない。
- 出典：[野菜の交配 - アストロノーカ非公式攻略wiki](https://astronoka.wiki.fc2.com/wiki/%E9%87%8E%E8%8F%9C%E3%81%AE%E4%BA%A4%E9%85%8D)、[配合 - アストロノーカ・PSP 攻略wiki](https://seesaawiki.jp/w/astronoka/d/%C7%DB%B9%E7)。規則で出した56通りは、すべて非公式攻略wiki の交配表に載っている（2026-10-12 に確認）。

- 穴ホウレン草だけでは、ニラクラウン・ひよこレモンが作れない（どちらもトマトニアンが親に要る）。トマトニアンは交配では作れない。
