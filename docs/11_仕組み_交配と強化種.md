# 仕組み：交配と強化種


交配・属性値・強化種の決まりと、ピート君・交配マシンの性能の数値をまとめた資料。作戦の判断は [ルート](20_ルート.md) に書く。

- 多くは Web の攻略情報と2人の解説から集めたもの。実機で確かめたものには日付を付けた。

## 1. ひと目で

- 子の品種は、両親のメンデル数の足し算と科の組み合わせで決まる。全56通りは [交配の全組み合わせ](14_交配の全組み合わせ.md)。
- 属性は、属性ごとに両親のどちらか一方のものを半々で受け継ぎ、そのあと変異属性の●が1つ反転する。
- 属性の段は●8個。初期値 +40 は●3個。
- 強化種は同じ野菜どうしの交配でできる。作れるのは、その野菜の変異属性の強化種だけ。掛けた結果が決まっている（Lv1 は●1つ、Lv2 は●2つ、Lv3 は●3つ増える）ので、引き直しが要らない。●が付く位置はでたらめ。
- 野菜の品質（「C級」「不良」などの級）は、属性値の合計で決まる。強化種を掛けた数とは関係ない。マイナスに上げた属性（重さ −200 など）は合計を下げる（走者、2026-10-18）。
- 上限が +200 の野菜は、それ以上その属性を上げられない。さらに上げたいときは、上限の高い野菜と掛けて移す。例：稀少模様レンコン（+200）× 冥王マツタケ → 模様 +201 以上のマツタケ。
- プラス側の強化種が作れるのは、その属性が +100 を越えた種どうしだけ。+40 前後の低い段では作れない（走者、2026-10-18）。だから +100 までの上げは、予言を見る属性上げを続けるしかなく、嘘に弱い。マイナス側は、ストロー級（重さ −61〜−97）のシマイモどうしで重さ強化種 Lv-1 が作れた（実機 2026-10-17）。
- 交配マシン：2号で変異が 100% になり、強化種が作れる。4号で強化種が 3号の2倍（約20%）。ファイナルでくず野菜がほぼ出なくなる。
- ピート君の嘘の率（[縛り動画](https://www.youtube.com/watch?v=6MrgUwe0oHo) の実測、各99回）：初期型 20%、セカンド 8%、サード 6%、スーパー 0%、ファイナル 0%。スーパーはソンブレロ市でしか買えないので、1年目の中盤はサードで交配する。

## 2. 品種の決まり方

- 子のメンデル数は、両親のメンデル数の足し算。
- 子の科は、両親が同じ科ならその科、違う科なら残りの科（A ＋ B → C など）。
- その科・メンデル数の野菜が無ければ、新しい品種はできない。
- 全56通りは [交配の全組み合わせ](14_交配の全組み合わせ.md)。
- 出典：[野菜の交配 - アストロノーカ非公式攻略wiki](https://astronoka.wiki.fc2.com/wiki/%E9%87%8E%E8%8F%9C%E3%81%AE%E4%BA%A4%E9%85%8D)

## 3. 種の数と、属性の引き継ぎ

### 種の数

- 交配は種を2つ使って、種が1つできる。失敗すると種を失う。
- 完全成熟まで育てると、野菜1つと種3つ。成熟の段階で収穫すると種は取れない。バブーに一度でもかじられると、収穫しても種は0個（実機 2026-10-14）。

### 属性の引き継ぎ

- 属性ごとに、両親のどちらか一方のもの（値と●の並び）を、ちょうど半々の確率でそのまま受け継ぐ。
- 違う野菜どうしでも、属性は親のどちらかから受け継がれる。たとえばシマイモで育てた軽さを、系統の先の野菜に残せる（走者の知識）。
- 変異属性でない属性は、交配では動かない（受け継ぐだけ）。たとえば重さはアストロキングの変異属性ではないので、交配では下がらず、強化種で下げる。
- たくさんの属性を引き継ぐほど、全部を狙った親から受け継ぐ確率が下がる（4属性なら 1/16）。ピートの予測で引き直して選ぶ。予測に出る属性は3つまでなので、4属性以上は確定では移せない（走者、2026-10-18。7. と 8. を見る）。
- 上級の野菜の +200 を超える値・−100 未満の値を普通の野菜に移すと、+200／−100 として扱われる。
- 交配していない属性の初期値は +40（複数の出典で一致）。

## 4. 属性値の決まり方

### 遺伝子と重み

- 属性ごとに、遺伝子が8個並んでいる（野菜の情報の画面の、丸や点）。
- 重みは左から 20, 8, 3, 15, 30, 5, 12, 7（合計 100）。
- 属性値 ＝ 段の基準値 ＋ ●になっている遺伝子の重みの合計。
  - 例：初期シマイモの重さは ●・・●・●・・ で、20 + 15 + 5 = 40。
- 8個が全部●になると「固定化」する。全部が・に戻り、段の基準値が 100 上がる（例：0 → +100）。
- 属性値の範囲：普通の野菜は −100〜+200、上級の野菜は −200〜+300。
- +40 から +300 にするのは、●21個ぶん。

### 交配で何が起きるか

- 交配すると、変異属性の遺伝子が1個だけ変わる（●→・ か ・→●）。交配マシン初号機は 50%、2号から 100%。
- どの遺伝子が変わるかは運。気に入らなければやり直す（ピートの予測を見て作らない、など）。
- ピート君は、交配する前に、できる野菜の名前と属性の称号（「ビタミン豊富」など）を教えてくれる。性能が低いと予測を間違える（7. を見る）。

### 称号と属性値（基準値 0〜+100 の段の場合）

称号は属性値で決まる。100 の幅に、ランクが3つある。

| ランク | 属性値 |
| --- | --- |
| +3 | 103〜130 |
| +2 | 73〜97 |
| +1 | 43〜70 |
| （なし） | 40 |
| −1 | 3〜39 |

- 上の段も同じ形（+4 132〜160、+5 162〜197、200 で GREAT、…、300 で FINAL）。
- 5番の遺伝子（重み 30）が●になると、称号がランクを1つ飛ばして上がることがある。
- 称号の段の中での●の増減は、予言（称号）では見分けられない（走者、2026-10-18）。
- 攻略サイトのおすすめは、ランクを「3, 2, 2, 1」個ずつの●で上げていくこと（合計 8個で固定化）。

### MAX の属性を交配すると

- MAX どうしを交配すると、変異で必ず1段下がる（交配マシンの変異が 100% のとき。複数の出典）。
- 食い違い：攻略サイト（変異属性が２つある場合）は「同じ種を2つ用意して自家受精すると避けられる」と書いている。同じ種どうしも MAX どうしの交配なので、上の「必ず1段下がる」と合わない。実機では確かめていない。
- 実機（2026-10-18）：形状 +300・風味 +270 の水晶ハーブ × 形状 +300・風味 +300 の貴婦人 でアストロキングを作ったとき、風味（変異属性）が落ちることがあり、形状と風味の両方が予言に出るまで約97秒（NO 約150回）待った。できた子は風味 +300 だった。

## 5. 交配のやり方の型

### 初期シマ交配法

上げたい属性を持つ種 × 初期シマイモ（50z）を何度も繰り返して、●を1つずつ増やすやり方。

- 初期シマイモは安いので、何度でも交配に使える。
- 欠点：上げたい属性以外は、どんどん消えていく。
- 属性を2つ持たせたいときは、それぞれの属性を別の種で上げてから、最後に交配して1つにまとめる。

### 同じ因子を持つ種どうし

- ●6 くらいまで上げた種を植えて増やし、同じ因子を持つ種どうしで掛けると、シマイモ相手より安定して上げられる。

### 平凡の種

- 初号機は 50% の確率で属性値が変わらない。これを使って、初期値のまま（「平凡」）の種を作れるのは初号機の間だけ（こんにゃく犬さんの解説、えぐ味さんの解説）。
- 平凡の種は、交配の相手にすると予測に余計なものが出ないので、後々まで使う（こんにゃく犬さんの解説）。

### 属性が2つある野菜

- 片方を上げると、もう片方が下がっていく。
- 両方を MAX にするには、●の数の偶奇をそろえる必要がある（片方が偶数なら、もう片方も偶数）。
- アストロキング（風味・音色）、貴婦人（形状・風味）、水晶ハーブ（風味・匂い）、スイカタワー（糖度・音色）、銀河ドリアン（栄養・匂い）は、どれも変異属性が2つある。

### 属性上げの回数の見込み（2026-10-16）

次の前提（子は親のどちらかの並びを受け継ぎ、1個がでたらめに反転。予測は称号だけ。引き直しとピートの嘘は数えない）で、プラス側に上げる交配の回数の平均を出した。強化種1個は、作る1回 ＋ 掛ける1回 ＝ 2回と数えた。

| 範囲 | 属性上げだけ | 強化種も使う |
| --- | --- | --- |
| +40 → +100 | 9.9回 | （+100 までは強化種を作れない） |
| +100 → +201 | 14.8回 | 11.1回（Lv1） |
| +40 → +201 | 24.7回 | 21.0回（Lv1） |
| +201 → +300 | 12.8回 | 7.0回（Lv1・Lv2）、5.0回（Lv3 まで） |
| +40 → +300 | 37.5回 | 28.0回（Lv1・Lv2）、26.0回（Lv3 まで） |

- 段の終わり（●が6〜7個になったあと）は、称号では進んだか分からず、戻ることも多い。強化種は、ここ（段100 の ●●・●●●●・ など）で使うと得になる。

## 6. 強化種

### 作り方

- 同じ野菜どうしの交配で、その野菜の変異属性の強化種ができることがある。できなければ普通の種になる。減る種は通常の交配と同じ2つ。
- 少なくとも片方の種の属性値が、+100 以上か 0 以下であることが条件（1つの出典のみ）。
- 変異属性でない属性は、交配で移しても強化種の元にならない。
- 強化種を作るには交配マシン2号以上が要る。

| 交配マシン | できる率 |
| --- | --- |
| 初号機 | 作れない |
| 2号 | 約3.5%（実機） |
| 3号 | 約10% |
| 4号以上 | 約20% |

### 強化種の Lv

Lv は、野菜のメンデル数と属性値で決まる。

| Lv | 条件 |
| --- | --- |
| Lv1 | メンデル数の低い野菜は、+200 でも Lv1 まで（透明キャベツの糖度、電灯キューリの食感） |
| Lv2 | メンデル数90以上の野菜の、大きさ・重さ・模様・栄養・糖度の +100〜+200 |
| Lv3 | +201 以上。大きさ・重さ・模様・栄養・糖度の5形質だけ |

- +200 ちょうどの冥王マツタケからは Lv2 しか取れなかった。
- メンデル数の低い野菜は、属性値の上限が +200 なので、それより上には上がらない。
- Lv-3 の強化種もある。

### 予言の見方

- ピートの性能が低いと、強化種は「特殊な野菜」と予言に出ることが多い。くず野菜も含むので、交配マシン・ファイナルになるまでは選ばない。

### 掛け方と効き目

- Lv1 は●1つ、Lv2 は●2つ、Lv3 は●3つ増やす。マイナスの強化種は、同じ数だけ下げる。
- ●が付く位置はでたらめ。
- 結果は決まっているので、予言を見ずに掛けられる。
- 予言に出ない4属性目以降も、強化種なら上げられる。
- 強化種と種を交配すると、必ず種が1つできる。強化種は1つ減る。
- 強化種どうしの交配は、必ずくず野菜になる。
- 作った野菜と違う品種にも掛けられる。
- 必要な数：+40 から +300 は Lv2 で11個、Lv3 で7個。初期値から −200 は Lv-3 で7個。
- 始めの値や●の付き方で、必要な数は増えることがある（実機では模様 Lv3 が8個）。
- ゴールデン強化種は、ほかの属性を動かさず、効果は1代だけ。
- ゴールデン強化種は最後に掛ける。あとで別の強化種を使うと、ゴールデンではなくなる。

### 店で買える強化種

- 店で売っているのは、ソンブレロ市の種屋の形状・風味・匂い・音色の Lv1 だけ。1個 10000z（実機でも匂い Lv1 8個が 80,000z）。
- 重さ・大きさ・模様・栄養・糖度・食感の強化種と、マイナスの強化種は売っていない。

### 取れる強化種（野菜ごと）

出典：[属性 - アストロノーカ非公式攻略wiki](https://astronoka.wiki.fc2.com/wiki/%E5%B1%9E%E6%80%A7) の「取れる強化種」（走者の調べ）。重さだけ実機で直した。

| 形質 | 取れる最大 | 元の野菜 |
| --- | --- | --- |
| 大きさ | +3 | 光速パイン |
| 重さ | +3、−3（Wiki の表は −2 だが、実機では −3 が作れた） | カブトタケノコ（イモ球は +2） |
| 模様 | +3 | 冥王マツタケ（火星カボチャは +2） |
| 栄養 | +3 | 銀河ドリアン（ニラクラウンは +2） |
| 糖度 | +3 | スイカタワー（ほかは +1） |
| 食感 | +2 | 宇宙マメ、冥王マツタケ |
| 形状 | +2 | 真空ワカメ、カブトタケノコ、チンゲンツリー、貴婦人 |
| 風味 | +2 | 月面コンブ、貴婦人、水晶ハーブ、アストロキング |
| 匂い | +2 | 砲丸ピーチ、トゲガーリック、銀河ドリアン、水晶ハーブ |
| 音色 | +2 | 光速パイン、スイカタワー、妖精ピーマン、アストロキング |

- Lv3 が取れるのは、上の5形質（大きさ・重さ・模様・栄養・糖度）だけ。形状・風味・匂い・音色は Lv2 まで。
- 変異属性を2つ持つ野菜は、1つ目が +3、2つ目が +2 のことが多い（スイカタワー：糖度 +3・音色 +2、銀河ドリアン：栄養 +3・匂い +2）。
- 上限 +200 の普通の野菜は、ほとんど +1 まで。

| ファイナル | 1000回 | 48.4% | 20.4% | 0.6% |

- 3号 → 4号：強化種が2倍になる。ほかは変わらない。
- 4号 → ファイナル：くず野菜がほぼ出なくなり、新種の率も上がる。
- ファイナルなら、ピートが予測を外しても、くず野菜にはまずならない。

### ピート君の「予測精度」の中身（こんにゃく犬さんの解説）

改造したときに協会の職員が「交配の予測精度がグンと上がる」と言う。こんにゃく犬さんは3つに分けている。

1. 予測を間違う確率（予測が「面白模様」でも「変な模様」の種になる、など）。RTA で一番大事なのはこれ。
2. 予測の数（緑色の文字。「ゆかいな模様」など）。
3. 予測の具体性（朱色の文字。「野菜」より「シマイモ」と出る）。

### 予測を間違える率（縛り動画の実測）

出典：ピートの「嘘つき予想」を検証した縛り動画 https://www.youtube.com/watch?v=6MrgUwe0oHo （こんにゃく犬さんが解説で言っていた動画）。要点は、走者が撮った画面による。

検証のやり方：夫婦喧嘩妖精ピーマン（音色 −143、ほかは +40）× 初期シマイモ（全部 +40）。予想に「絶叫悲鳴」（音色の称号）が出たところで交配し、99回ずつ、予想と違う結果になった回数を数えた。交配マシンの段階は画像からは分からない。

| 段階 | ウソの回数（実測） | ウソつき率 | 目安の幅（95%） | 動画の作者の事前予想 | こんにゃく犬さんの体感（解説動画） |
| --- | --- | --- | --- | --- | --- |
| 初期型 | 20 / 99 | 20.2% | 約 14〜29% | 10% | 約 1/4（25%） |
| セカンド | 8 / 99 | 8.0% | 約 4〜15% | 6% | 約 1/8（12.5%） |
| サード | 6 / 99 | 6.0% | 約 3〜13% | 4% | 約 1/16（6.3%） |
| スーパー | 0 / 99 | 0% | 0〜約 4% | 2% | 約 1/32（3.1%） |
| ファイナル | 0 / 99 | 0% | 0〜約 4% | 0% | 0 |

- 「目安の幅」は、99回の結果からこちらで計算したもの（ウィルソンの方法）。セカンドとサードの差は、この回数でははっきりしない。
- 実測は、こんにゃく犬さんの体感とおおむね合う。サードで 16回に1回くらい。
- スーパーで 0回。こんにゃく犬さんの「交配予測をほぼ間違えなくなりました」（こんにゃく犬さんの解説）、えぐ味さんの「ピート・ファイナルに嘘をつかれた記憶は一度もない」（えぐ味さんの解説）と合う。
- 検証したのは、違う野菜どうしで属性の称号を狙う交配の1種類だけ。えぐ味さんの検証では、新種ができる交配のほうが嘘をつきやすい（100回×5セットで、同じ種どうし29回、新種41回。えぐ味さんの解説）。交配の種類で率は変わるかもしれない。

### 予想の言い方と、予想できる属性の数（縛り動画の検証）

出典：同じ縛り動画の「予想精度の比較　進化段階ごとのまとめ」の画面。

| 段階 | 予想の言い方（ぼかした言い方） | 予想できる属性の数 |
| --- | --- | --- |
| 初期型 | 「なにか」「野菜」 | 1つまで |
| セカンド | 「野菜」「○○科野菜」 | 2つまで |
| サード | 「野菜」「○○科野菜」 | 2つまで |
| スーパー | 「野菜」「○○科野菜」 | 3つまで |
| ファイナル | 「○○科野菜」 | 3つまで（動いている属性は毎回全部出す） |

- ぼかした言い方は、野菜の名前の代わりに出る。段階が上がると「なにか」「野菜」が出なくなり、ファイナルでは「○○科野菜」だけになる。
- 新種の交配では「○○科野菜」で決めてよい。子の品種は両親のメンデル数の足し算と科で1つに決まるので、狙いの科（A 科と B 科の親なら C 科）が出た時点で狙いの野菜と確定する（走者、2026-10-18）。名前が出るまで待たなくてよい。待つのは「なにか」「野菜」と、くず野菜の予想のときだけ。
- サードは2つまで。こんにゃく犬さんの「今予測に模様無かったよね？でも3属性になっとる」（こんにゃく犬さんの解説、1年目 5/28）は、これで説明がつく。
- 「3属性までしか表示できない」（こんにゃく犬さんの解説）は、スーパー・ファイナルの値と合う。
- アストロキングの予言では、3つの欄のうち1つに変異属性（音色「気になる音」、風味）が入る。超軽量シマイモと掛けたときの予言は「神秘の形状で、気になる音で、超軽量な、アストロキング」で、風味は見えなかった（実機 2026-10-18）。
- 改造が進むと、くず野菜の予想と「野菜」という予想が減る（えぐ味さんの解説）。
- サードから、交配中にスタートボタンで「交配早見表」が見られる。RTA では使わない（こんにゃく犬さんの解説）。
- 間違える率で見ると、スーパーで十分。ただしファイナルは、親で動いている属性を3つまで毎回全部予言に出す（スーパーは0〜3個でばらばらに落とす）。強化種づくりでも「野菜」と言わないので、スーパーで「野菜」に隠れていた強化種が見える（実機 2026-10-24）。
- 強化種1個あたりの時間（スーパー → ファイナル）：糖度 Lv3 約21秒 → 約9.5秒、模様 Lv3 約17秒 → 約8秒、重さ Lv-3 約14秒 → 約12秒、栄養 Lv2 は約15秒で変わらない。ルートでは 2年目 1/28 にファイナルにする（ソンブレロ市の改造は1日に1段なので 1/21 はスーパーまで）。

### サードのまま中盤を交配するときの2人の対策

ピート・スーパーはソンブレロ市でしか買えないので、2人とも 1年目4月〜12月の交配はピート・サードで行っている。

- 種を量産してから交配する。例：メンデル●6 の種を9個用意して ●6 → ●7 を9回挑む。初期の種から一気に上げる攻め方はしない（こんにゃく犬さんの解説）。
- えぐ味さんも、固定化したら種を増やして「嘘の保険」にしている（えぐ味さんの解説）。
- 属性レベルが上がる手前では、強化種づくりをはさむ（こんにゃく犬さんの解説）。
- 予測を外された例：「きれいな形」の予測で「陽気な形」になった（5/14）。予測と違ったがメンデル●が増えたので良し、という例もある。2年目 1/1 にはイチゴブドウの予測で透明キャベツができてリカバリした（こんにゃく犬さんの解説）。

## 8. 改造で試行がどれだけ安定するか（見積もり）

「ピートと交配マシンを改造しきってから交配すればよいのでは」を考えるための見積もり。実機の値ではない。

| 原因 | 何が減るか | 効く改造 | サード・3号/4号 → スーパー以上・ファイナル |
| --- | --- | --- | --- |
| ① ピートの嘘 | 種（実行して失敗する） | ピート | 6% → 0% |
| ② くず野菜 | 引き直し（LR）の回数と、嘘のときの種 | 交配マシン | 約15% → 0.6% |
| ③ 予想に出る属性の数 | 何属性も引き継ぐ交配での種 | ピート | 2つまで → 3つまで |

- ① 1つの属性を +40 → +300 にするのは、成功する交配が約21回。サードの嘘 6% だと嘘は1〜2回、やり直しを1回あたり1〜2回とすると、増えるのは2〜3回（6〜13%増し）。嘘が良いほうに外れることもある（こんにゃく犬さんの解説）ので、実際はもう少し小さい。
- ② 3号・4号では、引き直しの約15%がくず野菜で無駄になる。ファイナルではほぼ無い。
- ③ サードで3属性を引き継ぐ交配をすると、3つ目は見えないまま 1/2 で受け継ぐので、その段の交配は約2倍。4属性なら約4倍。スーパー以上なら3属性まで見て選べる。4属性以上は、予想に出ないので確定では移せない（走者、2026-10-18）。

ここから言えること（作戦への使い方は [ルート](20_ルート.md)）

- 1つの属性を上げるだけなら、ピートを待っても得は小さい（種が1割ほど減る程度）。
- ピートを待つ値打ちがあるのは、何属性も引き継ぐ交配。
- 交配マシンは、ピートより早く改造したほうが効く。ピートと違って1年目のうちに（パンタロン町で）ファイナルまで買え、縛っているのはお金だけ。

### 予言待ちの見積もり（2026-10-18）

引き直し（NO）の回数と秒数を、ルートの段ごとに見積もった。前提は上の属性上げの見込みと同じで、1回の引き直しで出る子16通りが同じ確率、くず野菜（3号・4号で約15%）を引く。

- NO 1回の長さは、予想を見て判断する条件の数で決まる（走者、2026-10-18）。条件1つにつき約0.5秒（試走：新種が中心の4月は1回 約0.5秒、称号と作物名を見る5月は 約1.0〜1.1秒）。強化種・新種（科で決める）は1つ、属性上げは称号と作物名の2つ、何属性も引き継ぐ段は属性の数 ＋ 作物名。
- 試走との合い方：1年目4月の NO は計算 約186回・試走 約188回。5/14 のコンブ（●6 同士）は計算 交配約7回・試走8回。
- 見積もった時点（2026-10-18）の段で、通しの NO は約680回、秒数は約9分（毎回すべての条件を見るとき）。属性上げが約7分、強化種づくりが約2分、新種（科で決める）はほぼ0。
- 外れやすい条件（称号・属性）から見て、外れたらすぐ NO を押し、作物名は最後に見ると、約6分になる（約3分縮む）。属性上げの段はおよそ半分になる。
- 相手を同じ因子を持つ種にしても、2/7 のアートな模様・5/26 のコンブでは待ちはほとんど減らない。待ちの回数は遺伝子の仕組みでほぼ決まり、縮めやすいのは NO 1回の長さのほう。

## 9. 分かっていないこと

- 変わる遺伝子は8個から同じ確率で選ばれるのか。
- 強化種の Lv1・Lv2 ができるメンデル数の境目（メンデル数11 の透明キャベツは Lv1、90以上は Lv2）。
- MAX の属性を自家受精で守れるか（4. の食い違い）。
- 交配マシンの検証の率が、結果の率か予測に出た率か。初号機の検証値。
- ピートの嘘の率が、交配の種類（新種ができる交配、同じ種どうし）で変わるか。
- 実機で測っていないもの：引き直し（LR）1回の時間、難しい段（●6 → ●7 など）で目当ての予想が出るまでの引き直しの回数（サード／スーパー以上、3号・4号／ファイナル）、サードの予想がぼかした言い方になって目当てか見分けられない回の割合。
