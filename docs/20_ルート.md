# ルート

今のルートの要点をまとめた資料です。日ごとの作業は [ルートの日ごとの計画](21_ルート_日ごとの計画.md) にあります。

## 1. 方針

1. できるだけ安定していて、操作が少ない手順を選ぶ。
2. 畑を開く日の数より、交配の回数を減らすことを優先する。交配のほうが時間がかかり、つまずきやすい。
3. ゲーム内の日数は縮まらない。縮むのは1日を送る速さと作業の時間なので、何かをする日の数と操作の量で案を比べる。
4. コンクールや金策は、進行に必要なもの以外は、得られるお金でやるかを決める。
5. 強化種は作り置かず、掛けるときに作る。
6. 嘘に備えた余りは作らず、嘘が出たらその交配をやり直す。ホウレン草は多めに買う。

## 2. 変わらない条件

- ゴールは3年目 1/1 の全宇宙野菜コンクール。出場には A級で2勝が必要。
- 全宇宙の相手はテムジン 883点、シャルル 947点で固定。同点でも勝てる。
- 全宇宙の点は、品質の加算（ゴールデン 200）が大きい。属性は重さ以外の合計1点あたり約0.2点。実機では、ゴールデンで重さ以外の合計 1,615 は 927点で負け、1,699 は 947点で同点勝ちだった。

## 6. アストロキングの目標

| 形質 | 目標 | 作り方 |
| --- | --- | --- |
| 重さ | −200 | カブトタケノコの重さ強化種 Lv-3 を7個 |
| 形状 | +300 | 真空ワカメで +201、貴婦人へ移して形状強化種 Lv2 |
| 風味 | +300 | 月面コンブで +201、貴婦人へ移して風味強化種 Lv2 |
| 模様 | +300 | 冥王マツタケで +201 以上、模様強化種 Lv3 を8個 |
| 栄養 | +300 | 土星ナスから銀河ドリアンへ移し、栄養強化種 Lv2 を8個 |
| 糖度 | +300 | 透明キャベツからスイカタワーへ移し、糖度強化種 Lv3 を8個 |
| 匂い、音色 | +100 | 買った強化種 Lv1 を5個ずつ |
| 品質 | ゴールデン | 最後にゴールデン強化種を掛ける |

ゴールデン強化種を掛けたあとに別の強化種を使うと、ゴールデンではなくなります。

## 7. 再走の条件

| いつ | 条件 |
| --- | --- |
| 1年 1/28 ごろ | カカシ3体を突破されていたら |
| 罠を突破されたとき | 用意していた4つの形（5. の風船 → パンチングマシン → 川流し → 強力ジャンプ台と風船の川流し）がすべて抜かれたら |
| 交配に失敗したとき | 保険による立て直しが無理と判断したら |
| 2年 6/13 の夜 | ゴールデン強化種が無いとき |
