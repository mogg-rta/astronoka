# 仕組み：お金とコンクール

## 1. 野菜の売値の決まり

出典は [iridescent-chamber「野菜の値段」](https://www.iridescent-chamber.com/astronoka/price.html)。

- 売値 ＝（基本売却額 ＋ 属性ごとの補正値の和）× 状態の補正。
- 変異属性は、補正値が2倍になる。
- 10z 以下になるときは 10z。

## 3. 金策の比べ方

- 日数は全宇宙の日（3年目 1/1）で決まっている。「1日あたり」を上げてもタイムは縮まない。
- タイムに効くのは、畑を開く回数と操作の量。
- だから「畑を1回開いて得られる額（6マス × 売値）」で比べる。
- 属性で値段を上げた野菜は、基本売却額よりずっと高い。系統の途中で作る野菜を売るのが強い。

| 野菜 | 1つの売値 | 畑1回（6マス） |
| --- | --- | --- |
| 超軽量シマイモ | 690z | 4,140z |
| 冥王マツタケ（属性なし） | 1,800z | 10,800z |
| 2属性カブトタケノコ（重さ −200・形状 +300） | 2,700z | 16,200z |
| 3属性カブトタケノコ（重さ −200・模様 +300・形状 +300） | 3,000z | 18,000z |
| 2属性貴婦人（形状 +300・風味 +300） | 3,195z（実機 2026-10-18） | 19,170z |
| 3属性貴婦人（重さ −200・形状 +300・風味 +300） | 3,400z（計算上） | 20,400z |

- 状態の補正を掛けると、1. の表の倍率で上がる。
- 実例：こんにゃく犬さんは 1/25 に目標 260,000z を立て、3属性カブトタケノコを33個売る計画にしている。

## 5. ランクと全宇宙の出場条件

- 全宇宙に出る条件は「A ランクのコンクールで2勝」。進行フラグの中での位置は [進行フラグ](10_仕組み_進行フラグ.md)。
- A ランクは次の9つ。どれもソンブレロ市。

| 日 | A ランクのコンクール |
| --- | --- |
| 1/25 | 上級水晶ハーブ |
| 2/28 | 中級貴婦人 |
| 3/28 | 最悪野菜 |
| 4/28 | 上級冥王マツタケ、条件野菜 |
| 5/28 | 上級貴婦人、中級銀河ドリアン |
| 6/28 | 上級銀河ドリアン、総合チンゲンツリー |

- 上級 ＝ A ではない。中級（貴婦人・銀河ドリアン）も A で、パンタロン町の上級イチゴブドウは A ではない。
- 町だけで条件を満たす道はない。
- えぐ味さんの見立て：「難易度が比較的低めなのは貴婦人・マツタケ・ドリアン」「総合チンゲンツリーは全宇宙をしのぐ難易度」。

- B・C ランクの一覧は見つかっていない。

### 全宇宙の点（実機 2026-10-18）

同じアストロキング（重さ −200、模様・栄養・糖度・形状・風味 +300、大きさ・食感 +40）で、匂い・音色と出来を変えて出した。「合計」は重さ以外の属性値の合計。

- 属性によって重みが違うのかもしれない。
- こんにゃく犬さん（合計 1,968、すばらしい +150）の 955点も、ほぼこの線に乗る。

### ゴールデンは +200点

- えぐ味さんは、ゴールデンの野菜（ゴールデンウキウキパセリ、ゴールデン水晶ハーブ）をコンクールに出している。上級水晶ハーブは「ゴールデンの加点で勝たせてもらった」。
- 実機でも、同じアストロキングがとても良い 777点からゴールデン 927点になった（777 − 50 ＋ 200）。
- ゴールデン種の手に入れ方は「パンタロン町の若い娘のイベント」か「バブーに野菜を食べられたあとに落ちる」（Wiki の配合のページ）。落ち方は [バブーと罠](13_仕組み_バブーと罠.md)。
