# 仕組み：属性と称号

野菜の10の属性と、属性値ごとの称号（予言や野菜の名前に出る言葉）の一覧。予言で YES を押すかを決めるときと、強化種の数を見積もるときに使う。

出典：アストロノーカ・PSP 攻略wiki「属性一覧」（https://seesaawiki.jp/w/astronoka/d/%C2%B0%C0%AD%B0%EC%CD%F7 、2016-05-21 更新）。2026-10-24 に写した。

## 1. レベルと属性値

属性値は −200〜+300。100 ごとに段があり、段の中は称号で分かれる。

| --- | --- | --- | --- | --- |

| +8 | +261〜+297 | | Bad | +0 |
| +7 | +231〜+260 | | −2 | −3〜−30 |
| +6 | +203〜+230 | | −3 | −31〜−60 |
| Great | +200 | | −4 | −61〜−97 |
| +5 | +161〜+197 | | Devil | −100 |

| +3 | +103〜+130 | | −6 | −131〜−160 |
| Good | +100 | | −7 | −161〜−197 |
| +2 | +71〜+97 | | T.End | −200 |
| +1 | +41〜+70 | | | |
| 0 | +40（交配していない初期の値） | | | |

- ルートの言い方との対応：1段目は +40〜+97、2段目は Good〜+5（+100〜+197）、3段目は Great〜+8（+200〜+297）。「3段目●1以上」は +6 以上（+203〜）。
- マイナス側は、Bad（+0）から下へ、−2〜−4、Devil（−100）、−5〜−7、T.End（−200）。「マイナス2段目●8」は T.End。
- 段の中の●（因子）の数と属性値の関係は [11](11_仕組み_交配と強化種.md) の4章。

## 3. 変異属性（その野菜が伸ばせる範囲）

変異属性は、野菜ごとに決まっている属性で、交配で値が動く。

- 1年目に出る野菜は Great〜Devil まで伸ばせる。
- メンデル数の大きい野菜は Final〜T.End まで伸ばせる。

| 属性 | Great〜Devil の野菜 | Final〜T.End の野菜 |
| --- | --- | --- |
| 大きさ | 星カブ、イモ球、ゴボウ玉 | 光速パイン |
| 重さ | シマイモ、タマネギボム、カリフラボール | カブトタケノコ |
| 模様 | 腰かけレンコン、穴ホウレン草、ウキウキパセリ、火星カボチャ | 冥王マツタケ |
| 栄養 | トマトニアン、コスモニンジン、ニラクラウン、土星ナス | 銀河ドリアン |
| 糖度 | 透明キャベツ、ドームメロン、ホタル唐辛子、イチゴブドウ | スイカタワー |
| 食感 | 電灯キューリ、ロウソクコーン、宇宙マメ | 冥王マツタケ |
| 形状 | — | 真空ワカメ、カブトタケノコ、チンゲンツリー、貴婦人 |
| 風味 | — | 月面コンブ、貴婦人、水晶ハーブ、アストロキング |
| におい | ひよこレモン、砲丸ピーチ | トゲガーリック、銀河ドリアン、水晶ハーブ |
| 音色 | — | 光速パイン、スイカタワー、妖精ピーマン、アストロキング |

- 実機と合う例：透明キャベツの糖度は +200（極上甘味）まで、電灯キューリの食感は +200 までしか上がらない（[11](11_仕組み_交配と強化種.md) の6章）。
- 変異属性の売値の補正は2倍（[12](12_仕組み_お金とコンクール.md) の1章）。

## 5. 使い方

- 予言で待つ称号は、強化種で埋める前提なら、段（レベル）の始めで足りる。
- 例：2年目 2/1 の貴婦人 × 真空ワカメでは、風味 +6（トレビアーン）以上・形状 +6（魅惑の形状）以上が出れば、強化種 Lv2 を3個ずつで +300 にできる。
- +7（魅惑の風味）まで待つと、段を上げる待ちが重なる（NO 約110回）。
- 栄養の「健康になる」は Good（+100）、「解毒作用」は +3。
- 土星ナスの 1段目●7 は +2（栄養たっぷり）の中にあるので、称号だけでは ●6 と ●7 を見分けられない。
- 重さは、カブトタケノコを「ほとんど空気」（−5）にすれば、重さ強化種 Lv-3 が作れる。「空気より軽い」（−6）までは上げなくてよい。
