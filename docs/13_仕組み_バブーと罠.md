# 仕組み：バブーと罠

バブーと罠（トラップ）の仕組み、罠の性質、実績のある配置、ロード時間との関係をまとめる。罠を使うか、いつ切り替えるかの判断は [ルート](20_ルート.md) に書く。

## 1. バブーの仕組み

### 来る日

出典は [裏技](https://asutorono-ka.xn--1-td6bm19b.com/ura.html)。

- 日曜・祝日・記念日は来ない。実機でも日曜の夜は来なかった。
- バブー予報の数は「必ず来る数」で、ほかはランダム。
- 数は双眼鏡を覗いたときか1日の終了で決まる。
- 数はセーブされないので、ロードで変えられる。
- 罠の有無で来る回数は変わらないように見える。

### 来る畑

- 畑を1枚目から順に見て、好きな科の野菜がある畑で食べるらしい（[宇宙農家は豚キムチの夢を見るか](https://annex.2mk.org/tips/ps-astronoka/)）。
- 1つめの畑にダミーの野菜を植える方法がある。
- 4枚目に来た実例は見つかっていない（未確認）。
- 何も植えていない畑にも来る。
- 2年 3/7〜5/2 の食べさせでは、畑1 → 畑2 の順に移り、畑2の野菜もかじっていた（走者の見た感じ、10/25）。
- バブーには科の好き嫌いがある。シマイモ（B科）だけの畑だと「食べるものが無かった」とすごすご帰る個体もいる（走者 10/25）。

### 食べる量とかじられた野菜

- 1回に1〜2株（走者の知識。実機では1株）。
- 2年 3/7〜5/2 の食べさせでは、1匹につき1〜3回かじり、2回が多かった（走者の見た感じ、10/25）。
- エサを食べたバブーは、1回にかじる回数が増える（えぐ味さんの解説）。
- 発芽したあとは1株あたり2回まで、発芽前は1回までかじられる（走者 10/25）。
- 一度でもかじられると、収穫しても種は0個。売値は半値（傷物）。

### 行動と成長

- まっすぐ進む。同じ罠や道に近寄らない。飽き性で視野が狭い。
- ゲージは ①スタミナ ②やる気（残り時間） ③抵抗力（罠耐性）。③が満タンになると罠を突破、または破壊する。
- 同じ配置を続けると、意味不明な成長をしたバブーに蹂躙されることがある。スキップ時の芸術点が変わったら成長のサイン。
- SELECT でトラップバトルを飛ばせる（poinsgame は L2 と書いている）。

| 罠にかかったとき | 成長 |
| --- | --- |
| 落とし穴 | 脚力↑・体重↓・羽↑ |
| ぐるぐる台 | 体重↑ |
| とりもち | 脚力↑・体重↓・羽↑ |
| ジャンプ台 | 体重・脚力・ジャンプ力・迂回思考が成長 |

### 世代交代と突然変異

こんにゃく犬さんの解説（森川幸人氏の論文「テレビゲームへの人工知能技術の利用」1998年の紹介）による。論文そのものは読んでいない。

- 見えるのは1日1〜3体。
- 内部では約20体が罠の戦いを繰り返し、優秀な個体を交配して世代交代する（1日5〜10世代）。
- 突然変異は3%が基準。
- 進化がゆるやか（罠が少ない）と、世代交代が増え、突然変異確率が上がる。

突然変異の例：

- えぐ味さんは 1年目6月にバブーが変わり、1回にかじる回数が2回に増えて畑の手間が増えた。
- 実機では5月末から、扇風機の効かない「風に強いバブー」（バブボーン、バブモル）が増えた。

### 罠と品質

- トラップバトルの芸術点が 301 以上だと、野菜の品質が「すばらしい」になる。売値 1.5倍、コンクール +150点（[お金とコンクール](12_仕組み_お金とコンクール.md)）。
- 実機でも、芸術点 300 超えの夜を2回出して成熟で収穫した初期シマイモが「すばらしい」になった（2026-10-17）。
- 同じ川流しでも、バブーがそれまでに当たった罠で芸術点が変わる（2026-10-28）。

| それまでの罠 | 川流しの配置 | 芸術点 |
| --- | --- | --- |
| 1/10〜2/15 にカカシ3体を当て続けた | カカシ3体あり | 323〜335 |
| 2/18 まで罠なし | カカシ3体あり | 280 |
| 2/18 まで罠なし | カカシ抜き | 259〜264 |

- 走者の見立て：カカシに耐性をつけておかないと芸術点が上がらない。
- 川流しでバブーを流すのに、カカシは要らない（走者 10/28。カカシ抜きの川流しでも2晩は流せた）。カカシは芸術点を上げるためだけにある。
- 芸術点が要らなくなったら、カカシは売ってよい（1体 500z）。

### ゴールデン強化種

- バブーに野菜を食べられたとき（トラップバトルに負けたとき）に、低い確率で落ちる。
- 食べられた翌朝にピートが渡してくれる。
- 罠が無くても落ちる（poinsgame）。
- 罠で守りきると手に入らない。
- 品質（すばらしい）を取るには罠で勝つ必要があり、ゴールデンを拾うには負ける（食べさせる）必要がある。両方は同時に取れない。
- こんにゃく犬さんは勝率100%を狙ったので入手していない。

### ゴールデン強化種の落ちる率

結論：1匹あたり約2.0%。1日 0.94匹で計算すると、2年 3/7 から 5/22 までに出る見込みは約75%、6/13 までで約83%（[検証の結果](30_検証の結果.md) の 3.）。

| 測り方 | 食べた数 | 落ちた回数 | 率 |
| --- | --- | --- | --- |
| 2年 3/25 のセーブからくり返し | 184匹 | 7回 | 3.8%（95% の幅 1.5〜7.7%） |
| 2年 4/11 のセーブからくり返し | 310匹 | 4回 | 1.3%（同 0.4〜3.3%） |
| 罠なしで 3/25 から 6/1 ごろまで通し（10本）、4/10 まで | 135匹 | 3回 | 2.2% |
| 同じ10本、4/11 以降 | 441匹 | 9回 | 2.0% |

- 同じセーブからくり返し測れるのは、ロードし直すと、来る数、食べる株、ゴールデンの有無が毎回変わるため。
- 3/25 と 4/11 の差（両側 p ≈ 0.11）から「食べさせ続けると落ちにくくなる」かを確かめるため、罠なしの通し10本で測った。4/11 以降に 9回以上なら否定すると先に決めて、9回だったので否定した。

## 2. 罠の種類と性質

| 罠 | 性質・使い方 | 弱点・注意 |
| --- | --- | --- |
| ジャンプ台 | 横一文字に並べると、まっすぐ進むバブーが飛ばされる。一度起動した罠は二度と起動しない | 回避は迂回か飛び越えなので、体重・脚力・ジャンプ力・迂回思考が成長する。長く使うのは考え物 |
| 桂馬ジャンプ台 | 1年目2月4週から発売（700z）。ジャンプ台2台を置き換えて長持ちさせる | 重くなりすぎる、風に耐性がつくと突破される |
| ぐるぐる台 | 体重↑。二度連続で引っかけると元の方向へ戻る（諸説あり） | 単体では弱い |
| とりもち | 動けなくして「やる気」を削る。ぐるぐる台と組み合わせると同じとりもちに2度かけられる。低コスト | 通常は1回しか引っかけられない。消費型 |
| 落とし穴／浅底落とし穴 | 引っかけて体重を軽くできる。1/10 にピートから5個もらえる | 消費型。捕まえるとその穴は盤から消えて手持ちに戻るので、次の日に置き直す（実機）。かかってもジャンプで抜けられることがあり、そのときは穴が消費されて、バブーはそのまま先に進む（走者）。脚力が強い・迂回型・羽ありには弱い |
| ピートのカカシ | 怖がらせて迂回させ、やる気を削る。範囲は正面2マス、左右と後ろ1マス。3体で罠エリアのほとんどを覆う。壊れない限り置き直し不要。1体 1000z | 迂回型には弱く、後半は厳しい。カカシ耐性は序盤でかなり上がる。突破されると1体壊れる（残りは1体 500z で売れる、実機） |
| 危険なサイレン | カカシ系の最上級。範囲も効果も高い | 高価。うるさい |
| 風船サービス装置 | 「序盤最強トラップ」（こんにゃく犬さん）。2個並べるとジャンプでも押しても越えられない。破壊行動以外で帰ってもらえる。1個目は 100z（ご隠居、またはコンクール初優勝後）。2個目は羽15枚（パンタロン町のふとん屋）。売ると 5000z（実機 11/1） | 迂回するバブーには効かない。成長すると突破される |
| ただの塀／ワンダフルな塀／鉄壁の塀 | 凸型の壁。壁の先を落とし穴で囲み、迂回させて引っかけると羽つき・迂回型にも効く | 破壊されるし飛び越えられる。こんにゃく犬さんの試走ではクリアまで持たなかった |
| パンチングマシン | 6000z（トラップ屋）。スタミナを削る。攻撃方向を横向きにすると嫌われにくい。迂回型には風船から切り替える。風船を迂回するバブーの代わりになった走りもある | 高い。パンチングマシンも迂回される。3/28 に替えて 4/1 と 4/5 の夜に突破された走りがある（実機 10/31） |
| 冷水ぶっかけ装置／ビリビリマシン | 風船の代わりを試したが、迂回するバブーには風船と同じように迂回された（実機 10/31） | 迂回型には効かない |
| 2マス／3マス扇風機 | 起動すると回りっぱなしで何度でも引っかけられる。「川流し」にすると芸術点が高い。3マスは 5000z（2年目1月〜） | ヒット上限で自動停止。重くなる・風に耐性がつくと突破される。風に強いバブー（バブボーン、バブモル）には効かない（実機） |
| エサ（基本／良質／強力） | 高価なほど範囲が広く強い。誘導する、食べて帰ってもらう、落とし穴の出口に置いて何度も落とす | 消耗品。食べたバブーはかじる回数が増える。置いたエサが消えていることがあるので、罠の画面を開いた日は残っているかを見る（実機） |

- 羽はトラップ戦に勝つと増える（こんにゃく犬さんは 1年目 1/14 に1枚 → 3/27 に23枚）。
- 罠を使わないと羽は貯まらず、ソンブレロ市で買うしかない（10枚 10000z）。
- 罠の店は、新しい品が月末に入る。

## 4. ロード時間との関係

時間を決めるのは、バブーが来る夜の数。罠で増えるのは、配置の画面と置き直しの時間。

実機の測定（2026-10-17。14本の録画の約440晩）：

- 1晩は「暗転A（約6.5秒）→ トラップ戦（SELECT で飛ばした残り 約2.4〜2.7秒）→ 暗転B（約4.7〜5.2秒）」。
- 1匹来て守れた夜は、暗転Aの始めから朝まで 13.2〜14.5秒。
- 来ない夜の暗転は約1秒。
- 罠の数と種類では、読み込みは変わらない。2月の中で罠を3個・11個・6個と変えても、暗転B は 4.77〜4.87秒、暗転A は約6.5秒で同じ。
- 季節（月）では、暗転B が少しだけ伸びる（1月 4.73秒、5月以降 約5.0〜5.2秒）。畑が2枚になり株が増えたためか、季節のためかは分けられていない。
- 2匹来た夜は、2匹目の読み込み（5.7〜6.8秒）とトラップ戦（約2.4秒）が足されて、約8.5秒長い。
- 食べられた夜は、守れた夜より長い。1年目の測りでは約2秒。
- 罠なしで食べさせた2年目 3/25〜5/28 では、食べる場面が1匹あたり約10〜12秒で、川流しの夜より約7〜8秒長かった。
- 食べたい野菜が無いときは「すごすごと帰って」いき、短い。

2人の動画の比較：

| 走った人 | 罠 | 暗転の合計 | 罠の配置画面 |
| --- | --- | --- | --- |
| こんにゃく犬さん | 使った | 51:38 | 2:30 |
| えぐ味さん | ほぼ使わなかった | 48:47 | 0:36 |

- 暗転の合計はほとんど変わらない。
- 罠を置かなくても、バブーが来た夜はトラップバトルの場面と読み込みが入る。

そのほか：

- 罠を外したときの損は、夜の長さより、傷物と枯れた株の整地・廃棄と、売れる野菜が減ること。
- こんにゃく犬さんの説明：1日の終了後のロードの裏で、のべ100体以上のバブーが罠の戦いをしている（20体 × 1日5〜10世代と見れば、20体の説明と合う）。罠が少ないと世代交代が増えるが、それがバブーの強さにどう効くかは分かっていない。
- セーブ・ロードのやり直しは1回 約20秒（こんにゃく犬さんの解説）。
