# 超軽量シマイモを安定させる

超軽量シマイモ（重さ +40 → −100）は、称号の予言だけで上げると運で崩れやすい。ルートでは、途中で軽量に止めて種を増やし、最後は強化種で仕上げる。

## 作り方

| 日 | やること |
| --- | --- |
| 2/22 | 初期シマイモどうしで軽量（重さ 0。固定化して●8個）まで上げて止め、1株植える |
| 2/25 | 軽量を3株植えて増やす（2/28 に種9個） |
| 2/28 | 軽量を初期シマイモ相手にストロー級（重さ −61〜−97）まで上げる。残りの●が3個になったら、軽量 × 軽量 で重さ強化種 Lv-1 を作り、3回掛けて超軽量まで上げ切る |

- 軽量で止めて植えるのは、ピートの嘘で崩れても、軽量の種からやり直せるようにするため。
- 強化種は掛けた結果が決まっていて、●が必ず1つ減る。ストロー級の中で●を減らす段は称号では見分けられず運任せになるので、そこを強化種で飛ばす。
- 重さ強化種 Lv-1 は、重さ 0 以下のシマイモどうしで作れる（軽量 × 軽量 でも作れた。実機 2026-10-19）。
- この進め方（途中で止めて植え、種を増やしてから上げ、最後は強化種で上げ切る）は、ほかの属性上げにも採用している。
